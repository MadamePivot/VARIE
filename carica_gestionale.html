Carica dati dal gestionale

Due file, due caricamenti. Si può ripetere quando si vuole: le righe già presenti vengono aggiornate per ID, non duplicate. Non tocca contabilità né prima nota: riempie solo tabelle di appoggio.

1. Elenco fatture (CSV)

L'export dell'elenco fatture del gestionale, con le colonne ID, S., Num., Data, Cliente, Totale, Stato.

2. Pagamenti (SQL di phpMyAdmin)

Il file .sql della tabella pagamenti (solo FATT e FATT-NDC). Leggo soltanto le righe di dati: nessun altro comando del file viene eseguito.
